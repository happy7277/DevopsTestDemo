# 加个审批流

模糊需求样本。接口和响应供澄清讨论。

## 需求背景

部分动作希望先经他人审核，原话是「加个审批流」。

## 功能要求

- 澄清适用操作、角色、自审与拒绝原因
- 定义状态转换和超时

## 接口定义

`POST /api/approvals`

请求参数或请求体

```json
{
  "operation": "USER_DELETE",
  "targetId": 3
}
```

响应示例

```json
{
  "id": 12,
  "status": "PENDING"
}
```

## 验收标准

- [ ] 产品确认权限和状态机
- [ ] 审批前后对象状态清楚
- [ ] 明确并发决策与审计口径
