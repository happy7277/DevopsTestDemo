# 接口慢优化下

模糊需求样本。接口和响应供澄清讨论。

## 需求背景

用户列表偶发慢，原话是「接口慢优化下」。

## 功能要求

- 采集数据规模、并发、冷暖缓存和 p95
- 定位浏览器、代理、数据库或应用耗时

## 接口定义

`GET /api/users?page=1&size=10`

请求参数或请求体

```json
{
  "query": {
    "page": 1,
    "size": 10,
    "q": "ada"
  }
}
```

响应示例

```json
{
  "items": [],
  "total": 0,
  "page": 1,
  "size": 10
}
```

## 验收标准

- [ ] 确认目标接口和延迟目标
- [ ] 同负载记录优化前后分位数
- [ ] 分页数据和顺序一致
