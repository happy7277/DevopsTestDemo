# 看板上加个提醒

模糊需求样本。接口和响应供澄清讨论。

## 需求背景

运营希望及时看到异常，原话是「看板上加个提醒」。

## 功能要求

- 确认指标、阈值、基准期和时区
- 确认渠道及重复提醒预期

## 接口定义

`GET /api/dashboard/alerts`

请求参数或请求体

```json
{
  "query": {
    "from": "2025-01-01",
    "to": "2025-01-07"
  }
}
```

响应示例

```json
{
  "items": [
    {
      "metric": "new-users",
      "level": "warning",
      "date": "2025-01-04"
    }
  ]
}
```

## 验收标准

- [ ] 定义正常、异常和无数据样例
- [ ] 确认阈值和重复规则
- [ ] 确认可见角色
