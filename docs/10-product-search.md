# 商品搜索更智能一点

模糊需求样本。接口和响应供澄清讨论。

## 需求背景

商品目前按名称做文字包含，原话是「商品搜索更智能一点」。

## 功能要求

- 澄清 SKU、拼写容错、分词和排序
- 确认兼容性及无结果行为

## 接口定义

`GET /products?q=notebok`

请求参数或请求体

```json
{
  "query": {
    "q": "notebok",
    "limit": 20
  }
}
```

响应示例

```json
[
  {
    "id": 1,
    "sku": "DEMO-1",
    "name": "Demo Notebook",
    "price_cents": 250
  }
]
```
