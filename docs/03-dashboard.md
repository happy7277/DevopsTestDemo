# 数据看板

已在基线实现。

## 需求背景

运营需要查看每日新增及其当前状态。

## 功能要求

- UTC 按天统计并包含两端
- 缺少数据的日期补零
- 展示折线、柱状、饼图

## 接口定义

`GET /api/dashboard?from=2025-01-01&to=2025-01-01`

请求参数或请求体

```json
{
  "query": {
    "from": "2025-01-01",
    "to": "2025-01-01"
  }
}
```

响应示例

```json
[
  {
    "date": "2025-01-01",
    "active": 0,
    "disabled": 0
  }
]
```

## 验收标准

- [ ] 同日查询返回一天
- [ ] 倒序或超过 90 天返回 400
- [ ] 图表随日期更新
