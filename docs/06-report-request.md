# 做个报表导出

模糊需求样本。接口和响应供澄清讨论。

## 需求背景

运营希望在例会上用表格汇总，原话是「做个报表导出」。

## 功能要求

- 确认是用户明细还是看板汇总
- 确认列、文件格式和时间范围

## 接口定义

`GET /api/reports/export`

请求参数或请求体

```json
{
  "query": {
    "report": "user-overview",
    "from": "2025-01-01",
    "to": "2025-01-07"
  }
}
```

响应示例

```json
{
  "status": 200,
  "filename": "user-overview.xlsx"
}
```

## 验收标准

- [ ] 产品确认报表口径和最大导出量
- [ ] 确认空数据和超限规则
- [ ] 先提交澄清记录
